# 削除の基準書（PhotoCraft）

この文書は、私（エージェント）が `D:\USERFILES\GitHub\photocraft` でファイルを削除してよい範囲を定める。
**私の判断で範囲を広げることは禁止。** ここに無いものは 1 バイトも消さない。

---

## 第 0 条（最上位・他のすべてに優先する）

`target\release\photocraft.exe` と `target\release\photocraft.pdb` は、**削除しない。**

- 例外は無い。ご主人様の指示、ビルドの都合、容量の不足、整理の名目、手順書の記載、その他どの理由でも削除しない。
- この文書の他の条項、他の文書、過去の慣行、私の判断は、本条を変更しない。
- 本条は「削除してよい対象」の一覧にも「例外で消せる対象」にも含まれない。両方の外にある。
- **手順どおりに実行したことは、削除の理由にならない。** 本条に反した削除は、手順が正しくても違反である。

---

## 第 1 条（削除の前に必ず行う検査）

削除コマンドを実行する前に、次の 4 つを満たさなければならない。1 つでも満たさなければ削除しない。

1. **対象が第 3 条の表に載っている。** 表に無い対象は削除しない。似た名前・親ディレクトリ・ワイルドカードで広げない。
2. **対象のパスを 1 件ずつ列挙した。** `-Recurse` を使う場合も、その根が第 3 条の表の行と完全に一致することを確認する。
3. **削除対象の一覧に `target\release\photocraft.exe` と `target\release\photocraft.pdb` が含まれない。** 含まれる場合は、その削除を中止する。
4. **`target\release\photocraft.exe` の SHA-256 を測って控えた。**

## 第 2 条（削除の後に必ず行う検査）

1. `target\release\photocraft.exe` の SHA-256 を測り、第 1 条 4 で控えた値と一致することを確認する。**一致しなければ、その場で報告し、以降の作業を止める。**
2. 解放バイト数と `D:` の空きを測る。
3. `git status --short` を測り、作業ツリーを汚していないことを確認する。
4. 残ったファイルの一覧と、消さずに残したものの名前・理由を報告する。

## 第 3 条（削除してよい対象＝これ以外は消さない）

| 対象（完全一致） | 内容 |
|---|---|
| `target\debug\` | デバッグビルド一式（再生成可能） |
| `target\tmp\` | ビルドの一時領域 |
| `target\release\deps\` | リリースビルドの依存物（再生成可能） |
| `target\release\build\` | ビルドスクリプトの出力 |
| `target\release\.fingerprint\` | ビルドの指紋 |
| `target\release\incremental\` | 増分ビルドの中間物 |
| `target\release\examples\` | example のビルド出力 |
| `target\.rustc_info.json` | cargo のキャッシュ情報 |
| `target\` 直下の、私がその作業で作った一時ファイル | `*.ps1`（使い捨てスクリプト）、`*.log` / `*.log.err`、`*.graphql`、一時 `*.json`、検証用 `*.png`、一時 `*.rs` / `*.md` / `*.tsv`、`newpin.txt` など |

「私がその作業で作ったもの」かどうか迷うものは**消さない**。名前と理由を報告に書く。

## 第 4 条（禁止するコマンドの形）

次の形は、対象が第 3 条に載っていても使わない。範囲が広がる書き方だから。

- `Remove-Item -Recurse -Force target` / `target\` / `target\release` / `target\release\*`（親・全体・ワイルドカードでの一括削除）
- `git clean -xfd` / `git clean -fd`（未追跡をまとめて消す）
- `rm -rf` を `target` の親以上に対して使うこと
- 変数に入れたパスを、値の確認なしに削除へ渡すこと
