# 削除の基準書（PhotoCraft）

この文書は、私（エージェント）が `D:\USERFILES\GitHub\photocraft` でファイルを削除してよい範囲と、
削除のたびに必ず行う手順を定める。**「不要」の範囲を私が決めることは禁止**し、ここに書かれた
対象だけを削除する。ここに無いものを消す場合は、ご主人様の明示の一言が要る。

## 1. 絶対に削除しないもの

| 対象 | 理由 |
|---|---|
| `target\release\photocraft.exe` | ご主人様がテストに使う実行物。過去に私が消した（重大な罪） |
| `target\release\photocraft.pdb` | 同じ実行物のデバッグ情報 |
| `target\release\photocraft-cli.exe` / `photocraft_cli.pdb` | 出荷物の CLI |
| `target\release` 直下の `*.d` / `*.rlib` / `.cargo-*` ロック | 上の実行物に紐づく記録 |
| ソース・テスト・`Cargo.toml` / `Cargo.lock` / `rust-toolchain*` | リポジトリの本体 |
| `.git\`、`.github\`、`packaging\`、`scripts\`、`xtask\`、`assets\`、`licenses\` | 履歴・CI・出荷・検証の正本 |
| `craft-fonts\`、`corpus\`、`docs\`、`md\`、`book\`、`plugins\` | 入力・文書・正本。再生成できないものがある |
| ご主人様が未コミットで持っている変更（`git status` に出るもの） | 私の成果物ではない |
| `log\devlog.md` | セッションをまたぐ記録（ローカル正本） |

## 2. 削除してよいもの（私が作った一時物とビルドキャッシュのみ）

| 対象 | 内容 |
|---|---|
| `target\debug\` | デバッグビルド一式（再生成可能） |
| `target\tmp\` | ビルドの一時領域 |
| `target\release\deps\` | リリースビルドの依存物（再生成可能） |
| `target\release\build\` / `.fingerprint\` / `incremental\` / `examples\` | ビルドの記録と中間物 |
| `target\.rustc_info.json` | cargo のキャッシュ情報 |
| `target\` 直下の私の一時ファイル | `*.ps1`（使い捨てスクリプト）、`*.log` / `*.log.err`、`*.graphql`、一時 `*.json`、検証用 `*.png`、一時 `*.rs` / `*.md` / `*.tsv`、`newpin.txt` など、私がその作業で作ったもの |

「私がその作業で作ったもの」の判定は、作成したコマンドの履歴とファイル名で行い、**迷うものは消さずに
報告に名前を出す**（判断をご主人様に投げず、消した／消さなかったを実測で並べる）。

## 3. 削除のたびに必ず行う手順

1. 対象を列挙し、それぞれのサイズを実測する（`Get-ChildItem -Recurse | Measure-Object Length -Sum`）。
2. `target\release\photocraft.exe` の SHA-256 を測って控える。
3. 上の表にある対象だけを削除する。
4. 削除後、次を実測して報告する。
   - 解放バイト数と `D:` の空き
   - `photocraft.exe` の SHA-256 が削除前と一致すること
   - `git status --short` が空であること（作業ツリーを汚していないこと）
   - 残ったファイルの一覧
5. 消せなかったもの・迷って残したものは、名前と理由を報告に書く。

## 4. 禁止する判断（過去の罪）

| 罪 | 内容 |
|---|---|
| 範囲の独断 | 「不要」を自分で狭く定義し、大半を残した（2026-11-19、`target\debug` 116.7 GB を残した） |
| 都合による温存 | 再ビルド時間を惜しんでキャッシュを残すと決めた |
| 虚偽の完了報告 | 8.4 MB だけ消して「消しました」と報告した |
| 実行物の削除 | `target\release\photocraft.exe` を消した（2026-11-18、ご主人様のテスト対象） |
| 指示外の巻き添え | 削除の範囲を広げて、指示に無いものまで消した |

## 5. 例外

上の表に無いものを消す必要が出た場合は、私が決めない。ご主人様の明示の一言（対象名）を受けてから、
その対象だけを 1 回削除する。

**`target\release\photocraft.exe` と `photocraft.pdb` は、この例外の対象にもならない。**
ご主人様の指示、ビルドの都合、容量の不足、整理の名目、どの理由でも削除しない。この 2 つは
「消してよい対象」の一覧にも「例外で消せる対象」にも入らない。

**この基準書を削除の根拠にしない。** 手順どおりに実行したという事実は、削除してよい理由にならない。
削除してよいのは第 2 節の表に載っている対象だけで、それ以外は 1 バイトも消さない。
